Projects

SmartLab Empower API is a lightweight, containerized ASP.NET Core API designed to retrieve analytical data from the Oracle Empower 3 chromatography data system. Built with .NET 8, it provides a modern, structured interface for accessing Empower data programmatically—ideal for labs, LIMS integrations, and automated reporting workflows.
The API exposes multiple endpoints for retrieving Empower results by:
Sample set & result set pairs
Time‑range queries
Sample name & year
Result ID lookups
It supports local development via the .NET CLI and production deployment through Docker, making it easy to run in SmartLab environments or on any container‑ready infrastructure. Swagger documentation is included for quick testing and validation.
Tech Stack: C#, ASP.NET Core, Oracle.ManagedDataAccess.Core, Docker
Purpose: Streamline and modernize access to Empower 3 data for lab automation and SmartLab integrations.


LLE Analysis
I developed LLE Analysis, an automated computer-vision system for analyzing liquid-liquid extraction samples.
At its core is a custom YOLOv8 convolutional neural network that I trained using more than 2,000 images I manually annotated. As a laboratory robot moves each vial from a plate into the camera’s view, the model identifies key vial features and marks them with labeled bounding boxes.
The application then analyzes these detections to determine liquid-layer positions and volumes, meniscus types, rag layers, residue, measurements, and sample viability. Once the run is complete, it automatically generates a detailed Excel report containing the results and annotated images, then emails it directly to the scientist.
Technologies: Python, YOLOv8 CNN (convolutional neural network), PyTorch, OpenCV, Flask, Socket.IO, Pandas, OpenPyXL, and SQLite.


Disso Dissolution Platform
I designed and developed Disso, a full-stack web application that centralizes pharmaceutical dissolution study workflows and data. The platform enables scientists to create, duplicate, edit, review, approve, and securely lock study records while capturing detailed sample, method, media, instrumentation, and analytical parameters.
Disso also processes reports from Distek, ChemStation, Agilent, and ALMAC systems, transforming instrument output into structured data and Excel reports for analysis and visualization. The application reduces manual data entry and improves the consistency, traceability, and accessibility of laboratory study information.
Technologies: Python, Django, PostgreSQL, Pandas, SQLAlchemy, JavaScript, and Bootstrap
